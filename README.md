# Accedo

Wizytówka projektu uczniowskiego Zespołu Szkół nr 6 im. Króla Jana III Sobieskiego w Jastrzębiu-Zdroju. Accedo rozwija prototyp szkolenia VR, które ma pomóc nauczycielom przygotować się do włączania uczniów z niepełnosprawnościami w życie klasy.

## Uruchomienie

```sh
npm ci
npm start
```

Wersję do publikacji przygotowuje polecenie `npm run build`. Film i galeria są częścią repozytorium, w katalogu `public/assets`. Strona domyślnie używa preferencji językowych przeglądarki. Ręczny wybór zapisuje się lokalnie.

[Accedo na stronie szkoły](https://zs6sobieski.pl/accedo-inny-w-edukacji/)
